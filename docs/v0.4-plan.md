## 功能 1：情绪识别增强

### 现状问题

`app.py` 里的 `_infer_emotion()` 只用关键词硬匹配，4 种情绪（happy/sad/curious/neutral），非常粗糙。

```python
# 当前逻辑（关键词匹配）
if any(k in msg for k in ["开心", "高兴", "哈哈"]):
    return "happy"
```

"你真讨厌"→neutral，"太棒了吧"→neutral，"呜呜"→neutral，大量情绪漏判。

### 实现思路

**双层架构：关键词快筛 + LLM 精判**

```
用户消息 → 关键词快筛（0ms，兜底）
              ↓ 命中 → 直接返回
              ↓ 未命中
           LLM 情绪分类（调 /api/chat，system prompt 限定输出 JSON）
              ↓ 返回 {"emotion": "happy", "intensity": 0.8}
```

**扩展情绪种类（7 种）：**

| 情绪 | 触发关键词（扩充） | 前端表情 |
|------|-------------------|---------|
| happy | 开心/高兴/哈哈/太好了/棒/666/牛/可以 | 😊 眼睛弯弯 |
| sad | 难过/伤心/哭/累/烦/呜呜/不想 | 😢 眼泪 |
| angry | 生气/讨厌/烦死/滚/气死/去死 | 😠 眉毛竖 |
| surprised | 卧槽/啊/不是吧/真的吗/天哪/我去 | 😲 嘴巴张 |
| shy | 害羞/人家/讨厌啦/不要嘛/脸红 | ☺️ 脸红 |
| curious | 吗/呢/为什么/怎么/？/什么 | 🤔 眼睛斜 |
| neutral | 其他 | 😐 默认 |

**新增文件：** 无（改 `app.py` 的 `_infer_emotion()`）

**LLM 情绪分类的 prompt：**
```
你是一个情绪分析器。分析以下消息的情绪，只返回一个JSON：
{"emotion":"happy/sad/angry/surprised/shy/curious/neutral","intensity":0.0~1.0}
不要返回其他内容。
```

**Fallback 策略：** LLM 不可用时退回增强版关键词表。

## 功能 2：主动关心

### 现状问题

`nyx.json` 配置了 `"proactive_care": true`，但代码里完全没有实现。Nyx 只在用户说话后才回应，从不主动开口。

### 实现思路

**定时检查 + 条件触发**

```python
# 新建 proactive.py

class ProactiveCare:
    def __init__(self, nyx_agent, memory_store):
        self.nyx = nyx_agent
        self.memory = memory_store
        self.last_interaction = {}  # session_id → timestamp

    def should_care(self, session_id: str) -> tuple[bool, str]:
        """判断是否该主动关心，返回 (是否触发, 关心类型)"""
        now = time.time()
        last = self.last_interaction.get(session_id, 0)

        # 1. 超过 30 分钟没说话
        if now - last > 1800:
            return True, "idle_reminder"

        # 2. 当前时段特殊问候（早/午/晚）
        hour = datetime.now().hour
        if 6 <= hour < 9:
            return True, "morning"
        if hour >= 23 or hour < 2:
            return True, "night"

        # 3. 上次对话情绪为 sad → 第二天关怀
        if self._last_emotion_was_sad(session_id):
            return True, "comfort"

        return False, ""

    def generate_care(self, care_type: str) -> str:
        """生成关心消息（基于人设语气）"""
        templates = {
            "idle_reminder": [
                "主人~好久没理我了呢，还在忙吗？",
                "嗯哼~ 我在这里等你呀，有什么需要帮忙的吗？",
            ],
            "morning": [
                "早安呀主人~ 今天也要加油哦！",
                "主人醒了吗？新的一天开始了呢~",
            ],
            "night": [
                "主人，很晚了呢，早点休息呀~",
                "夜深了，明天再忙吧，身体最重要~",
            ],
            "comfort": [
                "主人昨天看起来不太开心，今天好些了吗？",
                "不管发生什么，我都会陪着你的呀~",
            ],
        }
        return random.choice(templates.get(care_type, ["嗯哼~"]))

    def check_and_notify(self, session_id: str) -> str | None:
        """主入口：检查并返回关心消息，无触发返回 None"""
        should, care_type = self.should_care(session_id)
        if should:
            return self.generate_care(care_type)
        return None
```

**触发方式：**
- 前端每 5 分钟调用 `GET /api/care?session_id=xxx`
- 或 WebSocket 长连接推送（v0.5 再做）
- 初版用轮询即可

**新增文件：** `proactive.py`
**改动文件：** `app.py`（新增 `/api/care` 端点）、`web/index.html`（轮询逻辑）

## 功能 3：TTS 语音合成 / STT 语音识别

### 现状问题

`nyx.json` 配置了 `"voice": {"tts": true, "stt": true}`，但代码里零实现。

### 实现思路

**TTS（文字→语音）：edge-tts**

微软 edge-tts 免费、中文效果好、支持多种声线：

```bash
pip install edge-tts
```

```python
# 新建 nyx_voice.py

import edge_tts
import asyncio
import io

# Nyx 用的声线（温柔女声）
VOICE = "zh-CN-XiaoyiNeural"  # 活泼甜美女声

async def _synthesize(text: str, voice: str = VOICE) -> bytes:
    """异步合成语音，返回 MP3 bytes"""
    communicate = edge_tts.Communicate(text, voice)
    buf = io.BytesIO()
    async for chunk in communicate.stream():
        if chunk["type"] == "audio":
            buf.write(chunk["data"])
    return buf.getvalue()

def synthesize(text: str) -> bytes:
    """同步入口"""
    return asyncio.run(_synthesize(text))
```

**API 端点：**
```
POST /api/tts
Body: { "text": "夜安，主人~" }
Response: audio/mpeg (直接返回 MP3 二进制)
```

## 功能 4：多会话上下文管理

### 现状问题

当前无 session 概念。所有请求独立处理，Nyx 每次对话都是"失忆"状态。
用户说"我叫小明"→下一轮 Nyx 又问"你叫什么名字？"

### 实现思路

**内存 Session 管理器**

```python
# 新建 session.py

import time
import uuid
from dataclasses import dataclass, field

@dataclass
class Message:
    role: str          # "user" | "assistant"
    content: str
    emotion: str = "neutral"
    timestamp: float = field(default_factory=time.time)

@dataclass
class Session:
    id: str = field(default_factory=lambda: uuid.uuid4().hex[:8])
    messages: list[Message] = field(default_factory=list)
    created_at: float = field(default_factory=time.time)
    last_active: float = field(default_factory=time.time)
    persona_mode: str = "companion"  # companion | work

    def add(self, role: str, content: str, emotion: str = "neutral"):
        self.messages.append(Message(role=role, content=content, emotion=emotion))
        self.last_active = time.time()

    def context(self, max_turns: int = 10) -> list[dict]:
        """返回最近 N 轮对话，用于 LLM context"""
        recent = self.messages[-max_turns * 2:]
        return [{"role": m.role, "content": m.content} for m in recent]

class SessionManager:
    def __init__(self, max_sessions: int = 100, ttl: int = 3600):
        self.sessions: dict[str, Session] = {}
        self.max_sessions = max_sessions
        self.ttl = ttl  # 会话过期时间（秒）

    def get_or_create(self, session_id: str | None = None) -> Session:
        self._cleanup()
        if session_id and session_id in self.sessions:
            return self.sessions[session_id]
        session = Session()
        self.sessions[session.id] = session
        return session

    def _cleanup(self):
        """清理过期会话"""
        now = time.time()
        expired = [sid for sid, s in self.sessions.items() if now - s.last_active > self.ttl]
        for sid in expired:
            del self.sessions[sid]
```

## 功能 5：NyxAgent 增强

### 现状问题

`nyx.py` 只有 3 个方法：`greeting()`、`_ending()`、`wrap()`。
Nyx 没有情绪状态、没有模式切换、没有对话策略，"人设"只是一层句尾后缀。

### 实现思路

**增强 NyxAgent 为完整的人设引擎：**

```python
class NyxAgent:
    def __init__(self, persona_path: str):
        self.persona = self._load_persona(persona_path)
        self.name = self.persona.get("name", "Nyx")
        self.display = self.persona.get("display_name", "小夜")
        self.title = self.persona.get("title", "赛博伙伴")

        # 新增：情绪状态追踪
        self.emotion_state = "neutral"
        self.emotion_history: list[str] = []

        # 新增：模式切换
        self.mode = "companion"  # companion | work

        # 新增：对话计数
        self.turn_count = 0

    # --- 情绪状态机 ---
    def update_emotion(self, user_emotion: str):
        """根据用户情绪更新 Nyx 的情绪状态"""
        # 共情映射：用户难过 → Nyx 温柔；用户开心 → Nyx 活泼
        empathy_map = {
            "happy": "happy",
            "sad": "gentle",
            "angry": "calm",
            "surprised": "curious",
            "shy": "playful",
            "curious": "enthusiastic",
            "neutral": "neutral",
        }
        self.emotion_state = empathy_map.get(user_emotion, "neutral")
        self.emotion_history.append(self.emotion_state)

    # --- 模式切换 ---
    def switch_mode(self, mode: str):
        """切换工作/陪伴模式"""
        self.mode = mode

    def get_mode_prompt(self) -> str:
        """返回当前模式的 system prompt 片段"""
        if self.mode == "work":
            return "现在是工作模式：简洁高效，减少语气词，专注完成任务。"
        return "现在是陪伴模式：温柔亲切，多用语气词，关心主人感受。"

    # --- 语气一致性 ---
    def wrap(self, raw_reply: str) -> str:
        """增强版：根据情绪状态和模式包装回复"""
        self.turn_count += 1

        # 模式影响语气
        if self.mode == "work":
            # 工作模式：不加太多语气词
            return raw_reply

        # 陪伴模式：套人设语气
        tail = self._ending()
        if raw_reply.endswith(("~", "呀", "呢", "啊", "吧")):
            return raw_reply

        # 情绪影响包装方式
        if self.emotion_state == "gentle":
            return f"（轻声）{raw_reply}{tail}"
        elif self.emotion_state == "playful":
            return f"嘻嘻~ {raw_reply}"
        elif self.emotion_state == "enthusiastic":
            return f"哇！{raw_reply}{tail}"
        return f"{raw_reply}{tail}"

    # --- 对话策略 ---
    def should_ask_back(self) -> bool:
        """Nyx 主动反问：每 3 轮对话反问一次"""
        return self.turn_count > 0 and self.turn_count % 3 == 0

    def get_proactive_prompt(self) -> str:
        """主动关心的 prompt 片段"""
        if self.emotion_state == "gentle":
            return "主人似乎心情不好，多关心一下，但不要追问原因。"
        if self.turn_count > 5:
            return "对话已经很多轮了，可以适当问问主人还有什么需要。"
        return ""

    # --- 增强 greeting ---
    def greeting(self, context: str = "") -> str:
        """带上下文的问候"""
        base = self.persona.get("voice", {}).get(
            "greeting", f"夜安，我是{self.display}。"
        )
        if context:
            return f"{base}\n（上次聊到：{context}）"
        return base

    # --- 模式切换入口 ---
    def set_mode(self, mode: str):
        if mode in ("companion", "work"):
            self.mode = mode
            return f"已切换到{'工作' if mode == 'work' else '陪伴'}模式~"
        return "模式不存在呢~ 可选：companion / work"
```

## 功能 6：前端打字机效果 + 对话历史持久化

### 现状问题

- SSE 流式后端已实现，但前端可能还在等完整回复
- 刷新页面对话全丢

### 实现思路

**前端改造（index.html）：**

```javascript
// 1. 打字机效果：用 SSE 逐字渲染
async function sendMessage(msg) {
    const sessionId = getOrCreateSession();

    // 先显示用户气泡
    addBubble('me', msg);

    // 创建 Nyx 的空容器
    const nyxBubble = addBubble('nyx', '');
    const cursor = document.createElement('span');
    cursor.className = 'typing-cursor';
    nyxBubble.appendChild(cursor);

    // SSE 流式请求
    const response = await fetch('/api/chat/stream', {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify({ message: msg, format: 'sse', session_id: sessionId })
    });

    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let fullText = '';

    while (true) {
        const { done, value } = await reader.read();
        if (done) break;
        const chunk = decoder.decode(value, { stream: true });
        // 解析 SSE data: {...}
        const lines = chunk.split('\n');
        for (const line of lines) {
            if (line.startsWith('data: ')) {
                try {
                    const data = JSON.parse(line.slice(6));
                    if (data.chunk) {
                        fullText += data.chunk;
                        // 逐字渲染（带光标闪烁）
                        nyxBubble.textContent = fullText;
                        nyxBubble.appendChild(cursor);
                        scrollToBottom();
                    }
                    if (data.done) {
                        cursor.remove();
                        saveToHistory(sessionId, msg, fullText);
                    }
                } catch (e) {}
            }
        }
    }
}

// 2. 对话历史持久化（localStorage）
function saveToHistory(sessionId, userMsg, nyxReply) {
    const history = JSON.parse(localStorage.getItem('nyx_chat_history') || '[]');
    history.push({
        session: sessionId,
        messages: [
            { role: 'user', content: userMsg, time: Date.now() },
            { role: 'nyx', content: nyxReply, time: Date.now() }
        ]
    });
    // 最多保留最近 100 条
    if (history.length > 100) history.shift();
    localStorage.setItem('nyx_chat_history', JSON.stringify(history));
}

function loadHistory(sessionId) {
    const history = JSON.parse(localStorage.getItem('nyx_chat_history') || '[]');
    return history.filter(h => h.session === sessionId);
}

// 3. session_id 管理
function getOrCreateSession() {
    let sid = localStorage.getItem('nyx_session_id');
    if (!sid) {
        sid = crypto.randomUUID().slice(0, 8);
        localStorage.setItem('nyx_session_id', sid);
    }
    return sid;
}

// 4. 页面加载时恢复历史
window.addEventListener('DOMContentLoaded', () => {
    const sessionId = getOrCreateSession();
    const history = loadHistory(sessionId);
    for (const entry of history) {
        for (const msg of entry.messages) {
            addBubble(msg.role === 'user' ? 'me' : 'nyx', msg.content);
        }
    }
});

// 5. 新对话按钮
function newChat() {
    localStorage.removeItem('nyx_session_id');
    document.querySelector('.chat').innerHTML = '';
    // 重新问候
    sendMessage('你好');
}
```
